2. 项目背景 二期已上线

2.1 业务背景

世宇科技与合作客户在游戏机台运营中存在分成关系。不同业务线（亿玩赏、爆玩宇宙、盲盒宇宙等）的分成对账方式各不相同，涉及门店发货、门店消耗、客户汇总等多种对账维度，且分成比例、结算周期、催款规则因业务线和合作模式差异而异。

传统线下对账方式依赖人工核对Excel表格、微信沟通确认，存在效率低、易出错、追溯难等问题。

2.2 数字化管理目标

智数后台实现从对账单生成 → 业务员核对 → 推送客户 → 客户确认 → 认款 → 账期管理 → 催款/锁机的全链路数字化管理，覆盖以下核心环节：

对账单生成
→
业务员核对
→
推送客户
→
客户确认
→
认款核销
→

功能描述

按门店维度生成亿玩赏消耗对账单。与发货对账单的区别在于对账依据不同：消耗对账基于机台投币消耗数据，而非发货记录。

与门店发货对账单的差异

对比维度门店发货对账单门店消耗对账单
对账依据机台发货记录（出货数量）机台投币消耗数据（实际消耗次数/金额）
特有字段：消耗次数无有（记录机台总消耗次数）
特有字段：消耗金额无有（按消耗计算的总金额）
金额计算逻辑发货数量 x 单价 x 分成比例消耗金额 x 分成比例
适用场景按出货量分成按实际运营消耗分成

10. 认款管理 二期已上线

认款管理是二期已上线的核心功能模块，用于管理客户回款的认款核销流程。业务员通过银行流水导入收款记录，在认款弹窗中将收款金额关联到具体客户和分成所属机台，完成认款核销后自动更新账期管理中的已收款数据。

10.1 认款列表 二期已上线

银行导入规则

银行流水导入规则
  • 导入方式：业务员从银行下载流水文件（Excel/CSV格式），通过系统导入
  • 文件格式：支持标准银行流水格式，包含流水号、收款金额、收款日期、付款方名称、摘要等字段
  • 自动匹配：系统根据付款方名称自动匹配合作客户，匹配成功率取决于客户名称一致性
  • 重复校验：同一银行流水号不可重复导入，系统自动去重
  • 未匹配处理：自动匹配失败的记录标记为"待认款"，需业务员手动认款
  • 认款状态：待认款 → 已认款 / 已忽略
!
银行导入仅导入银行流水记录用于认款匹配，不包含外部银行系统对接（API直连等）。业务员手动下载银行流水文件后上传至系统。
